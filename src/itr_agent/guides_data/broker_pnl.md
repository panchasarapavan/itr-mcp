# Broker tax P&L statement (generic)
File type: Excel (.xlsx) or CSV
1. Log in to your broker's web console or app
2. Open the reports section and choose the Tax P&L or capital gains report
3. Select the financial year, e.g. FY 2025-26
4. Download the file, including every sheet (equity, F&O, commodities)
Note: Brokers name these reports differently. Look for "Tax P&L", "Capital gains" or "Taxation".
