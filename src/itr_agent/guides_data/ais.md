# Annual Information Statement (AIS)
File type: JSON (preferred) or PDF
1. Go to https://www.incometax.gov.in and log in with your PAN and password
2. Open the AIS from the services or e-file menu (look for "Annual Information Statement")
3. Choose the financial year that matches the return, e.g. FY 2025-26 for AY 2026-27
4. Download the statement as JSON, or as PDF if JSON is not offered
Note: Portal menus change. If the option is not where described, search the portal for "AIS".
