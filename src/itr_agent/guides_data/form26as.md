# Form 26AS (tax credit statement)
File type: PDF
1. Go to https://www.tdscpc.gov.in and log in to TRACES with your PAN
2. Open Downloads, then the Form 26AS view or download option
3. Choose the assessment year, e.g. 2026-27
4. Download the PDF and keep the password the portal shows for it
Note: The PDF is usually password-protected. Check the password hint on the download page.
